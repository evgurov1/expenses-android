# Расходы

Android-приложение для учёта доходов, расходов и кредитов. Всё хранится и обрабатывается только на телефоне.

План проекта: стек, модель данных, импорт кредитов по фото и договору, расчёт долговой нагрузки (ПДН) и этапы MVP описаны в отдельном документе проекта.

## Что уже есть

- **Кредиты** (главный экран): потребительские, ипотека, авто, кредитные карты, микрозаймы. Платёж из договора или расчёт по сумме, ставке и сроку, график платежей, остаток долга.
- **Долговая нагрузка (ПДН)**: платежи по всем кредитам / доход в месяц, зоны 30/50/80%, прогноз, когда нагрузка снизится. Кредитная карта считается как 5% лимита.
- **Доход**: источники дохода, а если их нет — среднее по доходным операциям за 3 месяца.
- Счета с начальным остатком и текущим балансом.
- Категории доходов и расходов (стартовый набор создаётся при первом запуске).
- Ручной ввод операций, список по дням, итоги месяца, переключение месяцев.

## Стек

Kotlin, Jetpack Compose (Material 3), Hilt, Room, Navigation Compose. Минимальная версия Android 8.0 (API 26).

## Структура

- `core/domain` — чистый Kotlin: модели, работа с деньгами (в копейках), расчёты, интерфейсы репозиториев.
- `app` — Android: Room, DI, экраны.

## Сборка

```
./gradlew :core:domain:test :app:testDebugUnitTest
./gradlew :app:assembleDebug
```

Готовый debug-APK также собирается в GitHub Actions на каждый pull request (артефакт `expenses-debug-apk`).
